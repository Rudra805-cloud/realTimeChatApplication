# Real-Time Chat Application

A real-time chat application built using Node.js, Express, and Socket.IO.

## 🚀 Live Demo

https://chatapplication-9ht2.onrender.com/
---

## 📌 Features

- Real-time messaging
- Multi-user chat
- Responsive UI
- WebSocket communication
- Instant updates
- Username-based joining

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- Socket.IO

### Deployment
- Render
